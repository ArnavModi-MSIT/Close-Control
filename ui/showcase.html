01 · How it works

Six layers, one rule: the model proposes, code decides.

Every transaction flows through the same pipeline. Only the fraction the deterministic engine genuinely can't resolve on its own ever reaches an LLM — and even then, a separate, non-negotiable gate decides what happens next, and every escalation lands in a real human review queue.

Every box above is a real code path, not an illustration — trace any of it in matching/, agent/, investigator/, review_backend/, postgres/, redis/, or airflow/. Postgres, Redis, and Airflow are all local Docker containers — free, no cloud dependency, and each isolated from Airflow's own internal Postgres/Redis (its Celery broker), never cross-wired.
